# Needs you

**Needs you** is one list of what is waiting on you across the bots in the current space.

Open it from the inbox button in the sidebar, or go to `/app/needs`. The button carries a count
while anything is waiting.

## What appears

- A **question** or **approval** a bot posted in a chat.
- A **sign-in** or other protected request that needs the chat's form.
- A **takeover** request for a bot's computer screen.
- A **failed** run in a chat you have not read.
- A **routine** whose next scheduled run is overdue.

Each row opens its chat. Questions and approvals can be answered in place; sign-in and takeover
requests open the chat because they need the protected form or the computer.

## When it clears

The row disappears when the run resumes, the card is answered or dismissed, the failure is read, or
the routine runs. A bot's rows stay in the order they started, so the oldest item is first.

The list only shows items the signed-in person can act on. In a shared space, another member's
question, approval or failure stays out of your list.

On mobile, a **Needs you** row appears above the chat list while anything is waiting.
