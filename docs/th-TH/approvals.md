# การอนุมัติ

กำหนดว่า bot ทำอะไรได้โดยไม่ถามก่อน

## เลือกโหมด

**ตั้งค่า (Settings) → Approvals** เลือก **Mode**:

- **Ask** — ถามก่อนทุกการเปลี่ยนแปลง (ส่งอีเมล แก้เอกสาร ฯลฯ) การอ่านมักไม่ต้องถาม
- **Auto** — โมเดลตรวจว่าการกระทำตรงกับที่สั่งหรือไม่ ถ้าตรงจะทำต่อ ถ้าไม่ตรง หรือถ้าย้อนกลับไม่ได้ทั้งที่คุณไม่ได้สั่งไว้ bot จะถาม
- **Never ask** — ทำทุกอย่างโดยไม่รอ

**Auto** ต้องมี **Approval model** ใน **ตั้งค่า (Settings) → Models**

เริ่มที่ **Ask** หรือ **Auto** พออนุมัติการกระทำเดิมซ้ำ ๆ ให้เลือก **Always allow** บนการ์ด bot จะไม่ถามรายการนั้นอีก

## การ์ดในแชท

**Allow once** — ครั้งนี้  
**Always allow** (เครื่องมือหรือไซต์) — ไม่ถามอีก  
**Deny** — ข้ามการกระทำ

การ์ดไม่บล็อกแชท มีการแจ้งเตือนถ้าเปิดในการตั้งค่า bot

## รายการ Allow / Block

**ตั้งค่า (Settings) → Approvals** สลับ **Allow** / **Block** หรือ **Remove** รายการ Block จะปฏิเสธทันทีทุกโหมด

ปิดเครื่องมือต่อ bot: การตั้งค่า bot → **ขั้นสูง (Advanced)** → **Disable a tool**

## สิ่งที่ยังต้องถาม (Ask / Auto)

ในโหมด **Ask** และ **Auto** รายการต่อไปนี้ขึ้นการ์ดเสมอ และ **Always allow** ไม่ข้ามให้:

- เปลี่ยนคำสั่งหรือโมเดลของ bot และสร้าง space
- งานที่ข้อความที่คุณไม่ได้เขียนอาจชี้นำได้ เช่น การเปลี่ยนแปลงในรอบที่เริ่มจาก webhook
- routine ที่เฝ้าดูคำสั่ง หรือที่ระบุไซต์ซึ่งรอบนั้นพบจากเนื้อหาภายนอก

**Never ask** ทำรายการเหล่านี้ได้เลย ข้อยกเว้นเดียวคือการยอมรับการเชื่อม bot ของเจ้าของคนอื่น: ถ้าคนอื่นเป็นคนเริ่มรอบ หรือมีเนื้อหาจากภายนอกเข้ามา ระบบจะปฏิเสธ

## วงเงินจ่าย

เมื่อ bot จ่ายเงินได้ **ตั้งค่า (Settings) → Approvals** ตั้ง **Spending limit** (รายวัน สัปดาห์ หรือเดือน) การจ่ายที่เกินวงเงินจะถูกปฏิเสธก่อนที่จะถามคุณ
