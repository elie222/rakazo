# เชื่อมแอป

[English](../integrations.md) | ไทย

เชื่อม Gmail, Slack, Notion, GitHub และแอปอื่น ๆ เพื่อให้ bot อ่านและทำงานในแอปเหล่านั้นแทนคุณ

## เชื่อมจากแชท

วิธีที่ง่ายที่สุดคือขอ: "เชื่อม Google Calendar ของฉัน" bot จะโพสต์การ์ดในแชท เลือก **Connect** หรือ **Sign in**
แล้วลงชื่อเข้าใช้กับแอปให้เสร็จ

## เชื่อมจาก Integrations

บนเว็บและเดสก์ท็อป เลือก **เชื่อมต่อแอป (Connect apps)** ด้านล่างแถบข้างเพื่อเปิด **Integrations**
ค้นหาหรือเลือกดู **แอป (Apps)** ตามหมวดหมู่ สำหรับแอปในแคตตาล็อก เช่น Gmail ให้เลือก **เพิ่ม (Add)**

เมื่อเชื่อมแอปแล้ว ทุก bot ใน [space](../spaces.md) ใช้ได้ ไม่ต้องตั้งค่าทีละ bot เลือก **เพิ่มแล้ว (Added)**
เพื่อเปิดรายละเอียดของแอป แล้วเลือก **เพิ่มอีก (Add another)** เพื่อเชื่อมบัญชีอื่น หากต้องการเปลี่ยนชื่อบัญชี
แก้ป้ายกำกับแล้วกด Enter เลือก **นำออก (Remove)** ข้างบัญชีเพื่อตัดการเชื่อมต่อเฉพาะบัญชีนั้น
หรือ **ถอนการติดตั้ง (Uninstall)** เพื่อนำแอปออกทั้งหมด

> [!NOTE]
> แคตตาล็อกแอปขึ้นอยู่กับเซิร์ฟเวอร์ของคุณ เซิร์ฟเวอร์ self-host จะแสดงแคตตาล็อกเมื่อผู้ดูแลตั้งค่าแคตตาล็อกแอปไว้แล้วเท่านั้น
> ดู [Self-hosting](./self-host.md) แหล่งที่เพิ่มเองด้านล่างใช้ได้บนทุกเซิร์ฟเวอร์

## ใช้ปฏิทินและการเตือนความจำในโทรศัพท์

ในแอปมือถือ เปิดแชทข้อความส่วนตัวกับ bot แล้วถามว่ามีอะไรในปฏิทินของโทรศัพท์ หรือขอให้เพิ่มนัดหมาย
เปิดแชทนั้นค้างไว้และให้แอปอยู่บนหน้าจอระหว่างที่ bot ทำงาน นัดหมายในปฏิทินใช้ได้ทั้งบน iOS และ Android
บน iOS คุณยังขอให้ bot อ่าน เพิ่ม หรือทำเครื่องหมายว่าเสร็จสำหรับรายการเตือนความจำได้ด้วย ไม่ต้องเชื่อมบัญชีปฏิทินใน
**Integrations** เพื่อใช้ปฏิทินในโทรศัพท์

ถ้าโทรศัพท์ขอสิทธิ์เข้าถึง Calendar หรือ Reminders ให้อนุญาตเฉพาะเมื่อคุณต้องการใช้ฟีเจอร์นี้ ตรวจคำขออนุมัติในแชท
และตรวจปฏิทินหรือรายการเตือนความจำที่แสดงบนโทรศัพท์ก่อนยืนยันคำขอนั้น

## เพิ่มเครื่องมือของคุณเอง

GitHub, Linear และ Notion เชื่อมจาก Integrations ได้โดยตรงโดยไม่ต้องมีแคตตาล็อกแอปที่จัดการให้
GitHub ใช้ personal access token และเริ่มด้วยเครื่องมือแบบอ่านอย่างเดียว Linear และ Notion ลงชื่อเข้าใช้ผ่านเบราว์เซอร์
หากต้องการหานอกเหนือรายการในตัว ให้ค้นหาแอปแล้วเลือก **Search public MCP directory**
เพื่อดูผลจากไดเรกทอรีสาธารณะพร้อมกับผลอื่น ๆ

**+** ใน **Integrations** ใช้เพิ่มเครื่องมือที่ไม่มีในแคตตาล็อก:

- **MCP server**: MCP server ระยะไกลใดก็ได้ที่มีที่อยู่ HTTPS **Browse MCP servers** ค้นหาในไดเรกทอรีสาธารณะ
  เซิร์ฟเวอร์ self-host ยังรัน MCP server แบบ local (stdio) ได้ด้วย โดยผู้ดูแลเป็นผู้เพิ่ม ดู
  [Tools and integrations](../self-host-integrations.md)
- **OpenAPI** และ **GraphQL**: ชี้ไปที่คำอธิบายของ API แล้ว bot จะเรียกใช้ได้
- **Executor**: tool gateway ที่คุณลงชื่อเข้าใช้ด้วยบัญชี Executor ถ้าใช้ Executor แบบ self-host
  ให้เปลี่ยน URL เป็นที่อยู่ `/mcp` ของมันเอง
- **From GitHub**: ติดตั้งปลั๊กอินจาก repository ของมัน ดู [Build a plugin](../build-a-plugin.md)

เลือกวิธียืนยันตัวตน (**No auth**, **Bearer token** หรือ **API key header**) แล้วเลือก
**Verify and add** ข้อมูลรับรองถูกเข้ารหัสและไม่ถูกส่งไปที่โมเดล

**Manage MCP servers** แสดงทุกเซิร์ฟเวอร์ที่คุณเพิ่มไว้ พร้อม **Test connection** การลงชื่อเข้าใช้ OAuth
และ bot ที่ใช้แต่ละเซิร์ฟเวอร์ได้

การเรียกเครื่องมืออาจใช้เวลาหลายนาที และจะหยุดหลังหกนาทีถ้าไม่มีคำตอบหรือความคืบหน้าจากเซิร์ฟเวอร์

เซิร์ฟเวอร์ที่คุณลงชื่อเข้าใช้ (OAuth รวมถึง Executor) เก็บเซสชันเดียวไว้ให้คุณ ซึ่งทุกรอบการทำงานของคุณใช้ร่วมกัน
ระหว่างหนึ่งรอบของ bot ทุกการเรียกไปยังเซิร์ฟเวอร์ที่เพิ่มด้วย token หรือไม่มีการยืนยันตัวตนจะใช้เซสชันเดิม
เซิร์ฟเวอร์ที่เก็บสถานะไว้ในเซสชัน (เช่น ขั้นตอนที่หยุดรอให้คุณยืนยันกลางรอบ) จึงเห็นเซสชันเดียวกันจนรอบจบ
สองรอบไม่ใช้เซสชันแบบนี้ร่วมกัน และแต่ละเซสชันปิดเมื่อรอบจบหรือเมื่อไม่มีการเรียกประมาณสิบนาที ขั้นตอนที่หยุดไว้
ทำต่อได้เฉพาะเมื่อรอบยังทำงานต่อใน Rakazo instance เดิม ภายในช่วงเวลานั้นและช่วงเวลาของเซิร์ฟเวอร์เอง
หลังว่างสิบนาที หรือเมื่อรอบไปทำต่อบน instance อื่น การเรียกครั้งถัดไปจะเปิดเซสชันใหม่

Executor ขอให้ bot ทำขั้นตอนที่ต้องอนุมัติต่อ ขั้นตอนที่หยุดไว้จะหายไปถ้า Executor รีสตาร์ต
หากต้องการเชื่อมด้วย Executor access token แทนการลงชื่อเข้าใช้ ให้เพิ่มเป็น **MCP server** ด้วย
bearer token โดยใช้ token ขององค์กรเดียว

## แอปในแชท

MCP server บางตัวมาพร้อมแอป: มุมมองโต้ตอบขนาดเล็กของผลลัพธ์จากเครื่องมือ เช่น กราฟ แผนที่ หรือบอร์ด
เมื่อ bot ใช้เครื่องมือเหล่านั้น แอปจะแสดงในแชทเหนือคำตอบของ bot ทั้งบนเว็บ เดสก์ท็อป และมือถือ

แอปทำงานใน sandbox แอปเห็นเฉพาะการเรียกเครื่องมือนั้นและผลลัพธ์ เข้าถึงได้เฉพาะเว็บไซต์ที่เซิร์ฟเวอร์ประกาศไว้
และเรียกเครื่องมือหรือดูบัญชีของคุณไม่ได้ ลิงก์ในแอปจะถามก่อนเปิด และข้อความที่แอปแนะนำจะไปอยู่ในช่องข้อความให้คุณส่งเอง

## เลือกว่า bot ไหนใช้อะไร

bot เลือกแอปที่ต้องใช้เอง หากต้องการเพิ่ม MCP server ให้ bot ที่คุณคุยอยู่ เปิดเซิร์ฟเวอร์นั้นใน
**Integrations** แล้วเลือก **Use in this bot**

เมื่อ bot ต้องการเซิร์ฟเวอร์ที่ยังไม่เคยใช้ จะถามในแชทก่อน เลือก **Approve** หรือ
**Authorize** ถ้าเซิร์ฟเวอร์ต้องให้คุณลงชื่อเข้าใช้

## Available in

ถ้าคุณมีมากกว่าหนึ่ง [space](../spaces.md) ทุก skill, MCP server และปลั๊กอินที่คุณเพิ่มจะมีตัวเลือก
**Available in**: **All spaces** รวมถึง space ที่สร้างภายหลัง หรือเฉพาะ space ที่คุณเลือก
การเชื่อมแอปอยู่ใน space ที่คุณเชื่อมไว้

## API ที่ไม่มี integration

สำหรับบริการที่มีแค่ API key หรือการล็อกอินเว็บไซต์ ให้ขอให้ bot บันทึกไว้ ดู
[Reusable credentials](../bot-secrets.md)
