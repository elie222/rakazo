# เชื่อมแอป

เชื่อม Gmail, Slack, Notion, GitHub ฯลฯ ให้ bot อ่านและทำงานในแอปแทนคุณ

## จากแชท

พูดว่า "เชื่อม Google Calendar" bot โพสต์การ์ด — กด **Connect** หรือ **Sign in** แล้วลงชื่อเข้าใช้กับแอป

## จาก Integrations

กด **เชื่อมแอป (Connect apps)** ด้านล่างแถบข้าง ค้นหาใน **Apps** แล้ว **Connect**

เมื่อเชื่อมแล้ว ทุก bot ใน space เดียวกันใช้ได้ ไม่ต้องตั้งทีละ bot **Reconnect** / **Uninstall** ได้จากหน้าแอป

แคตตาล็อกขึ้นกับเซิร์ฟเวอร์ self-host ต้องให้ผู้ดูแลตั้งแคตตาล็อก (ดู [self-host](./self-host.md)) MCP, OpenAPI และ Treg เพิ่มเองได้บนทุกเซิร์ฟเวอร์

## เครื่องมือเพิ่มเอง

กด **+** ใน Integrations:

- **MCP server** — URL HTTPS
- **OpenAPI** / **GraphQL**
- **Treg**, **Executor**
- **From GitHub** — ปลั๊กอินจาก repo

เลือกวิธียืนยันตัวตน แล้วกด **Verify and add** ข้อมูลรับรองจะถูกเข้ารหัส และไม่ถูกส่งไปที่โมเดล

**Manage MCP servers** — ทดสอบการเชื่อมต่อ OAuth และเลือกว่า bot ไหนใช้

ระหว่างหนึ่งรอบการทำงาน การเรียก MCP ที่เพิ่มจาก Integrations ใช้เซสชันเดิม เซสชันปิดเมื่อรอบจบ หรือเมื่อไม่มีการเรียกประมาณ 10 นาที หลังจากนั้นการเรียกครั้งถัดไปจะเปิดเซสชันใหม่

## ใช้กับ bot ไหน

เปิดเซิร์ฟเวอร์ใน Integrations แล้วเลือก **Use in this bot** ถ้า bot ต้องการเซิร์ฟเวอร์ที่ยังไม่เคยใช้ จะขออนุมัติในแชทก่อน

หลาย space: ตั้ง **Available in** ว่าใช้ทุก space หรือเฉพาะที่เลือก การเชื่อมแอปอยู่ใน space ที่เชื่อม
