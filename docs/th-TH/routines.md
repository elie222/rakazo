# Routines

routine คือคำสั่งที่ bot รันเอง: ตามเวลา เมื่อมีการเปลี่ยนแปลง หรือเมื่อบริการภายนอกเรียก

## ขอในแชท

พูดเช่น "ทุกวันจันทร์ 8 โมงเช้า สรุปอีเมล" หรือ "เตือนอีก 20 นาทีให้โทรหา Dana" bot สร้าง routine แล้วรายงานในแชทเดิม

## สร้าง/แก้เอง

กด **Agent computer** ด้านบนแชท ใต้หน้าจอมี **Routines** → **Create Routine** (**+**)

1. ตั้ง **ชื่อ** และ **Instruction**
2. **When to run** → **Add trigger**
3. **Save**

**ขั้นสูง (Advanced)**: โมเดลและ Thinking แยกต่อ routine

## ทริกเกอร์หลัก

- **ตารางเวลา** — รายชั่วโมง/วัน/สัปดาห์ หรือ cron ใน **Advanced...** ใช้ timezone จาก **ตั้งค่า (Settings) → General**
- **เมื่อมีการเปลี่ยน** — ตรวจทุก X นาที รันเมื่อเปลี่ยน (ไฟล์ โฟลเดอร์ คำสั่ง หรือเครื่องมือแอป)
- **Webhook** — POST พร้อม URL และ key
- **Git event** — webhook จาก GitHub
- **อีเมล** — ส่งถึงที่อยู่ของ bot (ต้องเปิดรับเมลบนเซิร์ฟเวอร์)
- **Slack** — ต้องเชื่อม Slack ก่อน

รันจาก webhook หรือข้อความภายนอกมีกฎ [การอนุมัติ](./approvals.md) เข้มกว่า

## ทดสอบและหยุด

กด **Test run** จากรายการ routine เพื่อรันทันที ปิด **Active** เพื่อหยุดชั่วคราวโดยไม่ลบ ดูประวัติรันในแชทหรือรายการ routine
