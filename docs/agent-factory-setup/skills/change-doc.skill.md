# 变更说明（change-doc）

部署完成后产出变更说明。模板用 `docs/agent-factory-setup/templates/change-doc.md`，按仓库/团队约定回写（CHANGELOG、发布页、wiki 或内部文档）。

## 必须包含

1. **本次变更**：版本/提交、对应票、部署时间与环境。
2. **变更内容**：新增/修复/行为变化，各一两句。
3. **影响与注意**：兼容性、回滚方式、需要人工确认的事项。
4. **证据链接**：部署日志、健康检查结果。

## 写法

- 先写「一句话影响人看得懂的摘要」，再补细节；摘要不含内部地址与任何凭证。
- 影响面写清楚（谁受影响、是否需要手动动作）。
- 大变更拆小条目；小修小补不另起段落。

## 回写后的动作

- 票评论贴变更说明链接；群聊 @相关方摘要。
