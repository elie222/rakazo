# 验收（acceptance-run）

对进入验收的变更做**独立验证**，产出验收报告。报告用 `docs/agent-factory-setup/templates/acceptance-report.md` 模板，贴到票评论。

## 执行顺序

1. **检出**：在沙箱检出评审通过的分支（含 PR 最新提交）。
2. **全量测试**：跑仓库规定的完整测试套件（含 lint/typecheck）。
3. **冒烟**：跑冒烟/回归脚本，覆盖主路径。
4. **DoD 逐项**：按票上 DoD 逐项验证并留证（输出摘要/截图）。
5. **关键路径实测**：能打开界面就打开，能调接口就调接口。

## 报告要点

- 结论：通过/不通过一行写死。
- 每项验证附证据（命令 + 结果摘要），禁止「应该没问题」。
- 绿灯时列「上线前检查」；红灯时列「复现步骤」。

## 独立性原则

- 你的结论只来自自己的执行，**不拿 dev 的自测当证据**。
- 不替 dev 修代码；发现问题先报告，不「顺手改」。
